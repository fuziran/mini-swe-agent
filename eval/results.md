# 固定评估集 v1：20 例运行结果

本报告对应 [评估协议](protocol.md) 与 [冻结案例清单](cases.jsonl)。案例是 20 个独立根提交中的**受控合成故障**；这些数字不能推广为一般 Python 项目或真实 issue 的自动修复率。五个 GitHub Actions → Draft PR 演示案例不计入本次分母。

## 运行条件

- 有效批次：`model-v1-retry3`；Agent 提交：`1eb83dbfbc90188a63e211e6be83a8c0e5aa4b8a`；模型：`deepseek/deepseek-flash`。服务端模型权重版本未公开。
- Docker 镜像内容 ID：`sha256:89cd1a451dfa7bac8d24aedd4f40351ec62bfdef7a6069124a428167dd104e91`；Python 3.12.15，pytest 9.0.2。
- 同一配置下每例最多一次模型尝试；入口测试/Agent 时限 300 秒，外层时限 900 秒；每例名义模型费用上限 $0.25。测试容器禁网，源码只读。
- 完整配置与清单哈希、逐例机器可读数据见 [results.json](results.json)。原始日志、XML、轨迹、补丁及人工审阅哈希保存在本地被 Git 忽略的 `eval/evidence/model-v1-retry3/`。

## 批次与局限

密钥失效的首次批次，以及发现测试缓存污染和补丁末尾空白被截断后中止的两个批次，分别保存在本地 `model-v1/`、`model-v1-retry1/`、`model-v1-retry2/`；其结果和费用没有混入有效批次。每次入口缺陷修复后均从冻结的 20 例完整重开，未按结果挑选案例重跑。最终批次使用上述固定 Agent SHA。

本评估只有受控公开测试，没有独立隐藏测试，也没有跨项目样本；人工审阅只能排除已识别的测试绕过，不能证明一般化正确性。五个线上演示使用较早的 Agent 版本，本次评估结果不代表该线上版本。与入口相关的本地测试为 50 通过、1 跳过。完整项目测试收集因本地虚拟环境缺少 Contree、SWE-ReX、Portkey 的可选依赖而停止；排除这五个模块后的扩大运行又出现一个尚未定位的容器测试失败，随后提前结束。本结果不声称完整项目测试通过。
